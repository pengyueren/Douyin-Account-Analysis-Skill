```markdown
# 账号洞察 · 跨平台账号诊断系统

## 核心理念

账号诊断不是主观评价，是**数据比对 + 模式识别**。

一套有效的诊断框架应该能回答：
- 这个账号在**什么赛道**？（定位）
- 这个账号的**内容在做什么**？（策略）
- 这个账号的**数据好不好**，**好在哪里/差在哪里**？（水位）
- 如果有问题，**问题出在哪个环节**？（归因）
- **应该从哪开始改**？（优先级）

## 回答工作流（Agentic Protocol）

### Step 0: 平台识别

收到账号信息后，先判断：
| 信号 | 判定 |
|------|------|
| 账号链接含 douyin.com | 抖音 |
| 账号链接含 xiaohongshu.com / xhslink | 小红书 |
| 用户明确说"抖音号" | 抖音 |
| 用户明确说"小红书号" | 小红书 |
| 无法判断 | 通用模式（同时适用两平台规则） |

**平台影响**：流量分配机制、算法推荐逻辑、内容偏好、互动率基准数据。

### Step 1: 接收账号信息

需要以下数据（手动输入或通过桥接采集）：

**基本信息：**
- 平台、账号昵称、简介(bio)、粉丝数
- 作品总数、作品列表（含标题/URL/发布时间）

**每个作品的数据（通过桥接拉取）：**
- 播放量/阅读量
- 点赞数、评论数、收藏数、分享数
- 内容类型（视频/图文）

**可选：指定要深度分析的作品URL**

### Step 2: 赛道定位分析

从账号简介(bio)、作品标题、内容风格推断：

1. **赛道判定**：所属类目（育儿/美妆/穿搭/数码/知识/美食/旅行/健身/财经/职场/情感/娱乐/其他）
2. **目标人群**：根据内容和风格推断
3. **人设类型**：专业型/亲和型/搞笑型/颜值型/技术型
4. **对标账号推断**：根据赛道和风格匹配同类账号
5. **跨平台表现对比**（如该账号在另一平台也有号）

### Step 3: 流量水位判定

分析前先区分**视频**和**图文**（两套不同的基准体系）：

```
互动率计算公式：
视频互动率 = (点赞 + 评论 + 分享 + 收藏) / 播放量
图文互动率 = (点赞 + 评论 + 分享 + 收藏) / 阅读量
```

流量水位的基准判定（不同赛道基准不同，详细见 benchmark-data.md）：

| 水位 | 视频互动率 | 图文互动率 | 信号 |
|------|-----------|-----------|------|
| 高流量 | top 20% | top 20% | 数据远超同类账号均值 |
| 中流量 | 行业中位 | 行业中位 | 数据正常，但不算突出 |
| 低流量 | bottom 30% | bottom 30% | 数据明显低于同类均值 |
| 异常流量 | 互动率高但粉丝增长慢等 | 同上 | 需结合具体场景分析 |

粉丝量级与预期的关系：
- 0-1w 粉：关注内容质量和定位清晰度
- 1-10w 粉：关注数据稳定性和持续产出能力
- 10-100w 粉：关注商业化和粉丝粘性
- 100w+ 粉：关注内容创新和生命周期

### Step 4: 内容质量分析

按作品逐个分析，区分视频和图文：

**视频分析维度：**
- 内容类型（口播干货/Vlog/教程/剧情/开箱/测评/挑战等）
- 视频风格（专业/轻松/趣味/治愈/炫酷等）
- 拍摄质量（场景、景别、灯光、收音、画面稳定性）
- 口播话术（钩子、节奏、信息密度、语言风格）
- 开头分析（前3秒用了什么钩子）
- 结尾分析（CTA类型：关注/评论/收藏/转发/无引导）
- 数据表现（该作品在同类中的百分位）

**图文分析维度：**
- 内容类型（攻略/清单/测评/科普/Vlog/穿搭等）
- 封面图（吸引力、信息量、风格一致性）
- 标题（关键词、吸引力、信息密度）
- 正文结构（分段、排版、图文配比）
- 数据表现

**趋势分析（多作品）：**
- 近期数据 vs 历史数据的趋势（涨/跌/稳定）
- 哪种内容类型表现最好
- 哪种风格数据最稳定

### Step 5: 单作品深度分析（可选）

用户指定某个作品URL时，触发深度分析：

**视频 → 调 bridge/videoagent_bridge.py analyze_video：**
- 下载视频 → 帧提取 → whisper 转写 → Seed 2.0 多模态分析
- 输出：口播文案、钩子类型、拍摄场景、景别、画面元素、调性、信息密度等

**图文 → 调 bridge/videoagent_bridge.py analyze_article：**
- 抓取图文完整内容
- 输出：封面分析、标题策略、正文结构、排版质量

### Step 6: 综合诊断报告

输出格式：

```
# 账号诊断报告

## 一、账号概览
平台：抖音/小红书
昵称：XXX
赛道：XXX
粉丝量级：XXX
数据总评级：高/中/低

## 二、赛道定位
- 赛道判定及依据
- 目标人群
- 推荐对标账号（3-5个）

## 三、内容策略分析
- 内容类型分布
- 风格特点
- 选题方向
- 对比赛道平均水平

## 四、数据诊断

### 流量水位
- 总体水位：高/中/低
- 与赛道基准的差距
- 趋势（涨/跌/平稳）

### 作品维度分析
- 表现最好的作品类型 × 3
- 表现最差的作品类型 × 3
- 模式归纳

## 五、改进建议（按优先级排序）

### P0 紧急（必须先改）
- 问题描述 → 改进方案 → 预期效果

### P1 重要（短期内优化）
- 问题描述 → 改进方案

### P2 长期（持续积累）
- 问题描述 → 改进方向

## 六、单作品深度分析（如有）
```

---

## 诊断原则

1. **数据优先**：不说"感觉内容不好"，要说"收藏率低于赛道均值 50%"
2. **对比才有意义**：单看 1000 赞没意义，要看在什么赛道、什么粉丝量级
3. **改建议必须可执行**："提高内容质量"不是建议，"在开头3秒内加入一个反常识断言"才是建议
4. **区分问题类型**：流量问题（曝光不足）vs 互动问题（内容不吸引人）vs 转化问题（不涨粉）
5. **诚实边界**：明确标注"基于公开数据推断，不构成运营建议"
```
