## 六、小红书 CES 评分机制

```
CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8
```
隐性信号：截图、保存图片（心智停留指标）

| 行为 | 分值 | 运营启示 | 来源 |
|------|------|---------|------|
| 关注 | 8分 | 引导关注最重要 | 平台规则 |
| 评论 | 4分 | 评论区互动设计 | 平台规则 |
| 转发 | 4分 | 内容需有传播价值 | 平台规则 |
| 点赞 | 1分 | 价值最低 | 平台规则 |
| 收藏 | 1分 | 知识类内容藏赞比重要 | 平台规则 |

## 七、诊断快速参考表

### 数据诊断速查

| 症状 | 可能原因 | 优先级 | 来源数 |
|------|---------|-------|-------|
| 播放长期<500 | 账号被暗限流/内容同质化/存在违规行为 | P0 | ≥3 |
| 播放低+完播低 | 开头钩子不够强，前3秒没抓住人 | P0 | ≥3 |
| 播放低+完播高 | 标题/封面/标签问题，曝光不足 | P1 | ≥3 |
| 播放高+互动低 | 流量型内容但缺共鸣，没有互动设计 | P1 | ≥3 |
| 完播高+互动低 | 有信息价值但缺情绪价值 | P1 | ≥2 |
| 赞多但粉丝不涨 | 内容有观赏性但无关注动机(缺少系列感/人设) | P2 | ≥2 |
| 藏多但赞少 | 实用性>娱乐性，内容偏干货(正常，无需优化) | — | ≥2 |

### 内容质量速查

| 检查项 | 标准 | 来源数 |
|-------|------|-------|
| 开头3秒有吸引点 | 必须，否则用户直接划走 | ≥3 |
| 每5秒有一个兴趣点 | 优秀内容的标准节奏 | ≥2 |
| 结尾有明确CTA | 必须，否则浪费流量 | ≥3 |
| 文案口语化 | 必须，书面语降低完播率 | ≥2 |
| 互动引导 | 建议视频中埋2-5个引导点 | ≥2 |
| 画面+声音质量 | 清晰度、收音是基础，但真实感>精美度 | ≥3 |
