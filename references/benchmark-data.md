## 四、流量池层级递进标准

| 层级 | 播放量范围 | 核心考核指标 | 出池标准 | 来源数 |
|------|-----------|-------------|---------|-------|
| 冷启动池 | 200-500 | CTR + 完播率 | CTR达标+完播率达标，两者缺一不可 | ≥3 |
| 初级流量池 | 1,000-5,000 | 完播率持续达标 | 完播率稳定>15%，连续多视频达标 | ≥3 |
| 中级流量池 | 10,000+ | 完播率+互动率双优 | 完播率>30%+互动率>3%，双指标同时达标 | ≥3 |
| 高级流量池 | 100,000+ | 完播率+互动率+转发率综合 | 三项指标综合优秀，任一短板影响晋级 | ≥3 |

### 流量递进关键规则

- **前30分钟决定命运**：发布后30分钟内的数据表现决定能否进入下一流量池
- **逐级递进不可跳级**：必须从冷启动→初级→中级→高级逐级通关
- **每级考核重点不同**：冷启动看CTR+完播，初级看完播持续，中级看互动+完播双优

## 五、平台差异化基准

抖音推荐核心：行为概率预测（神经网络+100+目标），权重面板6:3:1
- 核心指标权重：完播率>互动率>收藏，深度互动信号权重上涨
- 流量来源：推荐流>70% + 搜索（搜推联动，搜索权重快速上升）
- 流量池启动：200→2000→20000逐级
- 完播率基准：25%+（行业均值）
- 审核机制：三审制（初审→复审→三审）
- AI内容政策：需标注AI生成
- 赛马机制：按视频时长分段竞争（<1min / 1-3min / 3-5min 各归各池）

## 六、平台评分机制详解

### 抖音算法机制

- **模型**：RankMixer-1B，200亿参数双塔模型
- **目标**：100+用户行为预测目标（不仅仅是互动）
- **核心逻辑**：行为概率预测而非单纯指标计数
- **数据采集点**：>100个，涵盖观看时长、滑动行为、停留、转发、关注等
- **权重三面板 6:3:1**：
  - 第一面板（60%）：完播率+均播时长+2秒跳出 — 受众反馈分，权重最高
  - 第二面板（30%）：互动率（点赞/评论/分享/收藏）
  - 第三面板（10%）：转粉率+关注行为
  - 后四个维度在作品发出瞬间已固定，只有受众反馈分持续变化
- **搜推联动**：搜索流量权重快速上升，创作者需布局标题关键词策略
- **算法演进趋势**：
  - 从「完播率优先」转向「深度互动信号优先」
  - 长评、转发等高质量互动行为权重在暴涨（昂贵信号理论）
  - "不后悔时长"概念兴起>纯完播率
- **赛马机制**：按视频时长分段竞争（<1min / 1-3min / 3-5min 各有独立赛道）
- **审核机制**：三审制（初审→复审→三审），爆款触发二次复核

## 七、诊断快速参考表

### 数据诊断速查

| 数据表现 | 可能原因 | 改进方向 | 优先级 |
|---------|---------|---------|-------|
| 播放长期<500 | 账号被暗限流/内容同质化/存在违规行为 | 三三制修复，暂停商业内容 | P0 |
| 播放低+完播低 | 开头钩子不够强，前3秒没抓住人 | 重做开场钩子 | P0 |
| 播放低+完播高 | 标题/封面/标签问题，曝光不足 | 优化标题/封面/标签 | P1 |
| 播放高+互动低 | 流量型内容但缺共鸣，没有互动设计 | 增加互动锚点 | P1 |
| 完播高+互动低 | 有信息价值但缺情绪价值 | 提升评论区互动钩子 | P1 |
| 中段流失集中 | 信息密度断档 | 调整内容节奏，每10s一个兴趣点 | P1 |
| 仅完播升+互动降 | 过度压缩内容 | 找回内容深度 | P2 |
| 赞多但粉丝不涨 | 内容有观赏性但无关注动机 | 增加系列感/人设 | P2 |
| 推荐页占比<70% | 账号被降权，推荐流量池被限制 | 检查违规、随拍诊断测试 | P0 |
| 推荐页占比<80% | 单条作品推流不足 | 优化标题/封面/标签，检查内容质量 | P1 |
| 粉丝播放占比>50% | 内容无法突破粉丝圈层 | 调整选题方向，扩大受众边界 | P1 |
| 藏多但赞少 | 实用性>娱乐性，内容偏干货 | 正常现象，无需优化 | — |

### 内容质量速查

| 检查项 | 标准 | 来源数 |
|-------|------|-------|
| 开头3秒有吸引点 | 必须，否则用户直接划走 | ≥3 |
| 每5秒有一个兴趣点 | 优秀内容的标准节奏 | ≥2 |
| 结尾有明确CTA | 必须，否则浪费流量 | ≥3 |
| 文案口语化 | 必须，书面语降低完播率 | ≥2 |
| 互动引导 | 视频中埋2-5个引导点 | ≥2 |
| 画面+声音质量 | 清晰度、收音是基础，但真实感>精美度 | ≥3 |
