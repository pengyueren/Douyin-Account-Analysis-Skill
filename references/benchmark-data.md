# 赛道基准数据

> 各赛道互动率水位基准。基于行业公开数据 + 多源交叉验证。
> 说明：不同赛道的内容属性和用户行为差异大，基准必须分赛道。
> 数据为近似值，需每6个月复核更新。

---

| 赛道 | 互动率中位数 | 高流量门槛（top 20%） | 低流量警戒线（bottom 30%） |

| 科技/数码 | 2-4% | >5% | <1.5% |
| 职场/创业 | 3-5% | >6% | <2% |
| 情感/人际关系 | 4-8% | >10% | <3% |
| 健身/运动 | 3-6% | >8% | <2% |

> 低粉账号（<1w）互动率通常偏高，大V账号（>100w）互动率通常偏低。

---

## 粉丝量级 × 期望互动率对照

| 粉丝量级 | 合理互动率范围 | 说明 |
|---------|--------------|------|
| 0-1k | 8-20% | 粉丝少所以互动率高，正常 |
| 1k-1w | 5-12% | 起步期，粉丝粘性较高 |
| 1w-10w | 3-8% | 稳定期，互动率开始下降 |
| 10w-50w | 2-5% | 规模化后互动率进一步稀释 |
| 50w-100w | 1.5-4% | 大V级别，基准继续下移 |
| 100w+ | 1-3% | 头部账号，互动率稳定在低位 |

> 核心逻辑：粉丝越多，互动率自然越低。诊断时不能只看互动率绝对值，
> 要看 **"在这个粉丝量级 × 这个赛道下，数据处于什么位置"**。

## 数据指标参考

| 指标 | 说明 |
|------|------|
| 平均播放量 | 近30天作品的平均播放/阅读 |
| 互动率 | (点赞+评论+收藏+分享)/播放量 |
| 收藏率 | 收藏/播放量（干货内容重要指标） |
| 评论率 | 评论/播放量 |
| 分享率 | 分享/播放量 |
| 粉丝增长率 | (新增-取关)/现有粉丝 |
| 完播率（视频） | 实际播放完成度 |
