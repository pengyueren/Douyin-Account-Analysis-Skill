## 一、分析维度体系

### 维度 1：赛道定位

| 评估项 | 判断标准 | 数据依据 |
|--------|---------|---------|
| 主赛道 | 内容主题集中度 ≥80% 为垂直 | 3H内容供给模型(Help 60-70%) |
| 目标人群 | 年龄/性别/兴趣推断 | 内容调性+互动人群特征 |
| 人设类型 | 专业/亲和/搞笑/颜值/技术/治愈 | 内容风格+出镜方式 |
| 定位清晰度 | 3秒内能否说清博主定位 | 简介+内容一致 |
| 垂直度 | ≥80%垂直/50-80%一般/<50%分散 | 跨赛道内容占比 |

### 维度 2：内容策略

| 评估项 | 判断标准 | 数据依据 |
|--------|---------|---------|
| 内容类型 | 口播/Vlog/教程/剧情/测评/挑战 | 内容分布分析 |
| 内容配比 | Help:Hub:Hero = 60-70%:20-30%:10% | 3H模型 |
| 视频结构 | 0-3s钩子 → 痛点 → 方案 → CTA | 标准脚本结构 |
| 钩子类型 | 5类经典钩子 | 见benchmark-data.md |
| 内容节奏 | 新号7-30s, 稳定期30-60s, 中长视频3-5min（2025-2026新增趋势） | 时长与赛道匹配，注意赛马机制按长度分段 |
| CTA设计 | 明确引导互动 | 每条视频必备 |
| 选题能力 | 50+选题库储备 | 金字塔选题模型 |

| 评估项 | 判断标准 | 数据依据 |

## 二、诊断归因框架

### 数据表现 → 问题归因

| 数据表现组合 | 诊断结论 | 改进方向 | 优先级 |
|-------------|---------|---------|-------|
| 播放低+完播高 | 曝光/点击问题 | 优化标题/封面/标签 | P1 |
| 播放低+完播低 | 开头/内容问题 | 重做开场钩子 | P0 |
| 播放高+互动低 | 缺共鸣/互动设计 | 增加互动锚点 | P1 |
| 完播高+互动低 | 有信息缺情绪 | 提升评论区互动钩子 | P1 |
| 赞多不涨粉 | 缺关注动机 | 增加系列感/人设 | P2 |
| 中段流失集中 | 信息密度断档 | 调整节奏 | P1 |
| 仅完播升+互动降 | 过度压缩内容 | 找回内容深度 | P2 |
| 播放长期<500 | 暗限流/冷启动失败 | 三三制修复，随拍诊断测试 | P0 |
| 推荐页占比<70% | 账号被降权 | 检查违规，随拍诊断区分账号/单条问题 | P0 |
| 推荐页占比<80% | 单条推流不足 | 检查标题/封面/标签/内容质量 | P1 |
| 粉丝播放占比>50% | 内容无法突破粉丝圈层 | 调整选题方向，扩大受众 | P1 |

## 三、内容质量评估清单

每条内容对照检查：

- [ ] 开头3秒有明确的吸引点（钩子）
- [ ] 前5秒流失率 <75%（5秒完播率 ≥25%）
- [ ] 每10秒有一个兴趣点或小起伏
- [ ] 有明确的痛点/共鸣点（3-10秒）
- [ ] 有解决方案或核心内容（10-25秒）
- [ ] 文案是否口语化
- [ ] 有2-5个互动引导点
- [ ] 结尾有明确的CTA
- [ ] 画面清晰+收音清楚
- [ ] 是否匹配平台特性（抖音重完播/小红书重搜索）

## 四、平台差异要点

### 抖音
- 核心：行为概率预测，权重三面板 6:3:1（完播互动60%+互动行为30%+转粉10%）
- 流量：推荐流 >70% + 搜索（搜推联动，搜索权重快速上升），200→2000→20000 逐级
- 内容：强娱乐、强视觉冲击、开场3秒定生死；中长视频3-5分钟趋势上升
- 赛马：按视频时长分段竞争（<1min / 1-3min / 3-5min 各归各池）
- 审核：三审制，爆款触发二次复核
- 时机：前30分钟决定能否进下一池
- 算法演进：完播率→深度互动信号优先，长评/转发权重大幅上涨

### 小红书
- 核心：CES评分（关8>评4>转4>赞1>藏1）
- 流量：推荐+搜索并行（搜索占比~50%）
- 内容：强实用、强信息密度、强真实感
- 搜索：日均6.2亿次搜索，70%月活使用
- 权重：原创35%、真诚分体系
- 商业：付费反哺自然，优质付费获3倍自然流量

## 五、诊断工作流

```
Step 0: 平台识别 → 确定抖音/小红书，选用对应基准
Step 1: 数据采集 → fetch-creator 获取创作者完整数据
Step 2: 赛道定位 → 判断赛道+目标人群+人设+垂直度
Step 3: 流量水位 → 互动率 vs 赛道基准 → 高/中/低水位
Step 4: 内容质量 → 钩子/结构/拍摄/制作/风格
Step 5: 运营细节 → 发布/标题/标签/评论区/互动引导
Step 6: 商业化分析 → 变现路径/商单/品牌/阶段
Step 7: 综合报告 → 问题定位+优先级排序+改进建议
```
