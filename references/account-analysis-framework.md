# 账号诊断分析框架

> 基于多源知识合成（WebSearch 方法论 + 行业基准数据 + 开源项目参考）
> 三审验证：跨源复现 ✓ | 有生成力 ✓ | 有排他性 ✓
> 适用平台：抖音 + 小红书 | 适用形态：视频 + 图文

---

## 一、账号诊断的五大核心维度

### 维度 1: 赛道定位与人设

| 子维度 | 诊断项 | 数据来源/依据 |
|--------|-------|-------------|
| 赛道判定 | 所属类目（育儿/美妆/穿搭/数码/知识/美食/健身/财经/职场/情感/娱乐） | 简介(bio) + 作品标题 + 内容风格 |
| 目标人群 | 年龄/性别/兴趣/消费能力推断 | 内容调性 + 评论区互动 |
| 人设类型 | 专业型/亲和型/搞笑型/颜值型/技术型/治愈型 | 出镜方式 + 表达风格 + 视觉调性 |
| 定位清晰度 | 3秒内能否说清"这个博主是做什么的" | 简介 + 内容垂直度 + 视觉统一性 |
| **人设-赛道一致性** | 内容是否垂直于主赛道 | 各作品标题/内容类的偏离度 |

### 维度 2: 内容策略

| 子维度 | 诊断项 |
|--------|-------|
| 内容类型分布 | 口播干货 / Vlog日常 / 教程 / 剧情 / 开箱 / 测评 / 挑战 / 情感 各自占比 |
| 选题方向 | 热点追踪 / 痛点解决 / 知识科普 / 情绪共鸣 / 经验分享 / 产品测评 |
| 系列化程度 | 是否有系列内容、栏目化运营 |
| 更新节奏 | 更新频率、发布时间规律性 |
| 视频结构 | [0-3s 钩子] → [3-10s 痛点/共鸣] → [10-25s 解决方案] → [25-30s 效果展示] → [30-35s CTA] |
| 图文结构 | 封面图吸引力 + 标题前18字含关键长尾词 + 正文信息密度 |

### 维度 3: 拍摄与制作（视频）

| 子维度 | 诊断项 |
|--------|-------|
| 拍摄场景 | 场景选择与一致性、布光质量、收音清晰度 |
| 出镜方式 | 单人直面镜头 / 双人互动 / 配音画面 / 纯文字动画 / 录屏 |
| 景别运用 | 近景特写 / 中景半身 / 远景全身 / 俯拍 / 多角度切换 |
| 画面元素 | 标题字幕、贴纸、分屏对比、商品特写、表情包 |
| 视觉调性 | 暖色调温馨 / 冷色调专业 / 高饱和活泼 / 黑白简约 / 自然清新 |
| BGM 选择 | 配乐风格、音量平衡、节奏匹配度 |

### 维度 4: 数据表现（核心）

**互动率计算公式：**
- 视频互动率 = (点赞 + 评论 + 分享 + 收藏) / 播放量
- 图文互动率 = (点赞 + 评论 + 分享 + 收藏) / 阅读量

**行业基准：**

| 指标 | 及格线 | 良好 | 优秀 |
|------|-------|------|------|
| 点赞率 | ≥3% | 3%-5% | 5%+ |
| 互动率（综合） | ≥3% | 3%-5% | 5%-8%+ |
| 收藏率（干货类） | — | ≥5% | ≥10% |
| 评论率 | — | ≥0.5% | ≥1% |
| 分享率 | — | ≥1% | ≥3% |

**CES 评分（小红书）：**
```
CES = 收藏×1 + 评论×4 + 转发×4 + 关注×8
```
评论与转发权重远高于点赞，收藏率高意味着"干货调性"。

**抖音流量池分层（参考）：**

| 流量层 | 播放量 | 主要推荐来源 |
|--------|-------|-------------|
| 初始流量 | 200-500 | 粉丝 + 标签推荐 |
| 初级流量 | 1k-5k | 标签推荐 + 同城 |
| 中级流量 | 10k-100k | 推荐页 + 搜索 |
| 热门流量 | 100k-1M | 推荐页算法助推 |
| 爆款 | 1M+ | 全渠道 + 可能上热搜 |

### 维度 5: 观众画像与运营

| 子维度 | 诊断项 |
|--------|-------|
| **观众来源健康度** | 首页推荐≥50% / 搜索占比因类目而异 / 个人主页10-30% / 关注<10% |
| 搜索流量占比 | 是否≥20%（过低说明关键词/标签不当） |
| 粉丝活跃度 | 僵尸粉比例、互动粉丝占比 |
| 评论区互动 | 作者回复率、评论区讨论深度 |

## 二、流量水位判定标准

| 评级 | 粉丝 ≤1w | 1w-10w | 10w-100w | 100w+ |
|------|----------|--------|----------|-------|
| 高流量 | 互动率 >8% | 互动率 >6% | 互动率 >5% | 互动率 >4% |
| 中流量 | 互动率 3-8% | 互动率 3-6% | 互动率 2-5% | 互动率 1-4% |
| 低流量 | 互动率 <3% | 互动率 <3% | 互动率 <2% | 互动率 <1% |

> 注意：不同赛道基准差异大。美妆/穿搭类互动率基准高于知识/新闻类。
> 详细赛道基准数据见 benchmark-data.md

## 三、内容质量评估

### 视频评估表

| 维度 | 好 | 一般 | 差 |
|------|------|------|------|
| 开头钩子 | 前3秒有强烈钩子（反常识/痛点提问/数据冲击） | 有钩子但不够尖锐 | 无钩子或铺垫过长 |
| 信息密度 | 每30秒有1-2个信息点或情绪点 | 部分段落信息冗余 | 大量冗余/凑时长 |
| 口播节奏 | 语速适中+关键点强调+停顿节奏 | 节奏平稳但无高潮 | 语调平淡/过快/过慢 |
| 结尾CTA | 明确引导互动（关注/评论/收藏） | 有引导但不具体 | 无引导/突然结束 |
| 拍摄质量 | 画面稳定+光线充足+收声清晰 | 有轻微瑕疵不致命 | 明显噪点/晃动/噪音 |
| 视觉设计 | 画面元素丰富+风格统一+信息适量 | 有设计但不突出 | 画面单调/杂乱 |

### 图文评估表

| 维度 | 好 | 差 |
|------|------|------|
| 封面图 | 信息明确+视觉吸引+风格统一 | 随意拍摄/文字过多/模糊 |
| 标题 | 含关键词+有吸引力+信息完整 | 标题党/无关键词/信息空洞 |
| 正文结构 | 分段清晰+图文搭配+重点突出 | 大段文字/无配图/难以阅读 |
| 信息量 | 有干货/有情绪/有价值 | 流水账/无核心观点 |

## 四、改进建议推理框架

### 第一步：定位问题类型

| 问题信号 | 可能原因 | 验证方式 |
|---------|---------|---------|
| 播放量低 | 内容不够垂直/封面标题不够吸引 | 对比同赛道同类内容 |
| 互动率低 | 内容触发情绪不够/引导不足 | 检查钩子和CTA |
| 收藏率高但赞少 | 实用性强但娱乐性不足 | 适合做干货类内容 |
| 涨粉慢 | 人设不清晰/缺乏持续关注价值 | 检查内容系列化程度 |
| 评论少 | 没有讨论引导/评论区不活跃 | 看是否设置了讨论话题 |
| 单条爆了但其他一般 | 选题偶然性大/非可复现模式 | 分析爆款与日常的区别 |

### 第二步：归因到维度

```
流量问题 → 维度1(赛道定位) + 维度2(内容策略)
互动问题 → 维度2(内容策略) + 维度3(拍摄制作)
涨粉问题 → 维度1(人设清晰度) + 维度5(运营)
商业问题 → 维度5(变现路径)
```

### 第三步：排优先级

```
P0 紧急（必须先改）：
  - 赛道定位模糊
  - 严重违规/限流
  - 内容引不起任何互动（互动率<1%）

P1 重要（短期内优化）：
  - 开头钩子太弱
  - 更新频率不稳定
  - 封面/标题吸引力不足
  - 缺少系列化内容

P2 长期（持续积累）：
  - 拍摄质量提升
  - BGM和画面风格统一
  - 人设深度打磨
  - 评论区互动规范
```

## 五、对标账号分析方法

筛选对标账号的标准：
- 优先选 **粉丝量 1-30w 的成长型账号**（打法更贴近起号者）
- 不要只看大V（大V打法不可复制）

分析一个对标账号需回答4个问题：

1. **🎯 定位**：对方讲什么？为谁服务？
   - 看主页简介、内容一致性、人设设定
2. **🧱 内容结构**：视频/图文结构怎么搭？
   - 起承转合、脚本逻辑、节奏切换
3. **🪝 引爆点**：为什么火？爆在哪？
   - 视觉钩子、情绪点、反差点、话题引导
4. **💰 变现路径**：他怎么赚钱？
   - 评论引导、橱窗产品、主页跳转、私域转化

## 六、数据源说明

本框架基于以下来源合成：
- WebSearch 搜索结果（抖音/小红书运营方法论文章）
- 行业基准数据（多来源交叉验证）
- social-account-doctor（GitHub 开源项目参考）
- 行业常见分析维度（跨源复现验证）

> **诚实边界**：
> - 各赛道基准数据需要持续更新（建议每6个月复核）
> - 平台算法频繁变化，某些判定标准可能过时
> - 诊断结论基于公开数据分析，不能取代专业运营判断
